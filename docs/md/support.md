# ObjectRadar Support

Thank you for using ObjectRadar.

If you encounter a problem or have any question, please contact: contact.elab@mailo.com

When contacting support, please include:

- iPhone model
- iOS version
- ObjectRadar version
- Description of the issue

We will review your request and provide assistance whenever possible.

## Contact topics

Please select the category that best matches your request:

- General contact
- Support
- Bug report
- Feature request
- Translation

Selecting the appropriate topic helps us to process your request more efficiently.
