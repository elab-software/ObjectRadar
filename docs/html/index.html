Object Radar

Find nearby Bluetooth objects with intelligent BLE guidance.

Overview

Object Radar helps you locate nearby Bluetooth objects and compatible BLE accessories using local Bluetooth signal analysis.

Designed with privacy in mind, all Bluetooth processing is performed directly on your device.

Features

  • Bluetooth Low Energy (BLE) scanning
  • Nearby object tracking
  • Known and unknown device identification
  • Personal object association
  • Real-time signal guidance
  • Local processing only

Privacy

Object Radar does not use any server for Bluetooth analysis. No location history or personal information is collected.

Bluetooth limitations

Bluetooth signal strength provides an estimation of proximity only. Actual detection distance depends on the accessory, surrounding environment, obstacles, radio interference and the Bluetooth transmitter power. Object Radar assists you during the final search but cannot determine an exact physical position.
